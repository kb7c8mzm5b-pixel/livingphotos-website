# LivingPhotos website

English-first, German-language static website for LivingPhotos on Apple TV.

Target: https://livingphotos.strouhal-hoferichter.de

## Setup
1. GitHub repository Settings > Pages > Build and deployment > Deploy from a branch; select main / (root).
2. Set custom domain to livingphotos.strouhal-hoferichter.de and enable Enforce HTTPS once the certificate is issued.
3. In DomainFactory DNS: CNAME host livingphotos -> kb7c8mzm5b-pixel.github.io (do not change root domain or MX).
4. Review both privacy notices and legal notices before making the public site discoverable. Add final screenshots and replace temporary SVG with original app logo.

No app source code is included.
